# Sistema de Login e Cadastro

Este projeto foi desenvolvido com o objetivo de praticar conceitos de desenvolvimento web utilizando JavaScript puro, com foco em manipulação do DOM e gerenciamento de dados no navegador.

## 🚀 Tecnologias utilizadas
- HTML
- CSS
- JavaScript

## 💻 Funcionalidades
- Cadastro de usuários
- Login de usuários
- Recuperação/atualização de senha
- Armazenamento de dados no navegador
- Controle de sessão utilizando sessionStorage
- Manipulação dinâmica de elementos com DOM

## 🧠 Conceitos aplicados
- Manipulação do DOM
- Estruturação de lógica em JavaScript
- Armazenamento de dados no navegador (sessionStorage)
- Controle básico de autenticação no front-end

## 📌 Objetivo
Aplicar na prática conceitos fundamentais de desenvolvimento web, simulando um sistema de autenticação de usuários.

## ⚠️ Observações
- O projeto ainda não é responsivo
- Os dados são armazenados localmente (não há integração com banco de dados)

## ▶️ Como executar
1. Baixe ou clone este repositório
2. Abra o arquivo `index.html` no navegador
